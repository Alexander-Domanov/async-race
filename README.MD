# Async Race

A Single Page Application built with TypeScript and the native DOM API.

The application allows users to manage cars, run races, control car engines, and track race winners using a REST API.

## Technologies

* TypeScript
* Vite
* Vanilla JavaScript DOM API
* Fetch API
* CSS
* REST API

## Development

The project is currently under development.

The application source code will be developed in a separate `async-race` branch.
